# Eureka Ring Landing Page：双语、品牌与移动端设计规格

**日期：** 2026-07-20  
**状态：** 已确认，待实施  
**范围：** `ring-demo` Landing Page；不包含 Flash/Vibe 真机 Demo 页面

## 1. 目标

在不改变现有桌面端叙事与贯穿式戒指滚动的前提下，为 Landing Page 增加：

- 基于访问地区的中英文自动选择；
- 可手动覆盖并记忆的语言切换；
- Eureka 品牌 Logo 的克制露出；
- 真实微信群二维码；
- 一套完整、可用且性能可控的移动端布局与戒指路径。

最终页面仍是一套 React 组件与一条戒指旅程，不复制中英文页面，也不把已隔离的 Flash/Vibe Demo 路由重新接回 Landing Page。

## 2. 已确认的产品原则

### 2.1 语言默认值

- 首次访问由 Vercel Routing Middleware 读取请求国家代码。
- `CN` 默认显示中文；其他国家或无法识别地区默认显示英文。
- 页面不展示语言选择入口页或首次访问弹窗。
- 页面右上角保留紧凑的 `中 / EN` 手动切换。
- 用户手动选择写入 Cookie，并始终优先于 IP 推断。
- 不存储原始 IP；只使用 Vercel 请求中已经提供的国家代码。

### 2.2 品牌命名

- 产品名继续使用 `Eureka Ring`。
- 用户提供的 Eureka 图形 Logo 作为母品牌标识，不替代产品名。
- Logo 只在首屏品牌签名和最终 CTA 使用，避免每屏重复造成视觉噪声。

### 2.3 戒指叙事

- 桌面端保留现有贯穿整页的单一 3D 戒指 Canvas。
- 移动端仍保留戒指随滚动经过各 Section 的核心体验。
- 不为移动端复制第二套 Canvas；使用同一个 Journey 状态与独立的移动端锚点映射。
- 中英文切换不能重置滚动位置、重新加载 GLB 或生成重叠戒指实例。

## 3. 信息架构与品牌落点

### 3.1 首屏

首屏左上品牌签名由纯文字调整为：

1. Eureka 图形 Logo；
2. `Eureka Ring` 产品名；
3. 当前语言下的简短品牌说明。

Logo 在桌面端保持小尺寸，不与主标题“智能 · 触手可及”争夺视觉层级。英文标题使用对应的两行英文表达，继续沿用现有 Shuffle 动效。

语言切换放在首屏右上角，视觉上使用轻量文本切换，不使用大型胶囊或设置面板。

### 3.2 中间内容

所有可见文案、图片 `alt`、ARIA 标签、场景标题和按钮文字迁移到双语内容字典。以下内容不翻译：

- 产品名 `Eureka Ring`；
- 软件与服务品牌名；
- `Flash`、`Vibe` 等既有模式名称中的英文品牌词。

中文继续采用当前标点和排版节奏；英文不逐字直译，而按产品 Landing Page 的自然英文重写，控制每个标题的视觉长度。

### 3.3 最终 CTA

最终 CTA 保留深色背景，结构调整为：

- 左侧：Eureka 小型品牌落款、招募标题和说明；
- 中间：滚动旅程结束时的银色戒指；
- 右侧：真实微信群二维码和扫码说明。

二维码使用用户提供的原图作为源文件。页面通过容器裁切聚焦真实二维码区域，不显示截图中具有时效性的“7 天内有效”说明；网页自身提供稳定的 CTA 标题与说明。二维码资源路径固定，后续只需替换同名图片即可更新。

英文页面仍显示同一个微信群二维码，说明文字改为英文，并明确为 WeChat group。

## 4. 国际化技术方案

### 4.1 内容结构

将当前单一 `LANDING_CONTENT` 拆为：

```ts
type Locale = "zh-CN" | "en";

const LANDING_CONTENT: Record<Locale, LandingContent> = {
  "zh-CN": { /* 中文 */ },
  en: { /* English */ },
};
```

组件通过 Locale Context 或等价的轻量 Provider 读取当前内容。避免引入重量级 i18n 库，因为当前只有两种语言、无复数规则和动态后端文案。

### 4.2 首次语言解析

优先级固定为：

1. 用户手动语言 Cookie；
2. Vercel 地理国家代码；
3. 无 Vercel 上下文的本地开发回退：浏览器语言；
4. 最终回退：中文。

项目根目录增加 Vercel `middleware.ts`：

- 只匹配 HTML 页面请求；
- 跳过静态资源、GLB、图片、字体和 API；
- 若已有手动语言 Cookie，直接继续；
- 否则读取地理位置并在响应中写入初始语言 Cookie；
- 不重定向到 `/zh` 或 `/en`，保持当前单页 URL 和已有锚点不变。

部署时 Vercel Project Root Directory 必须设为 `ring-demo`，使 `middleware.ts` 与该应用的 `package.json` 位于同一级。项目显式加入 `@vercel/functions`，使用其 `geolocation()` 与 `next()` helper，避免依赖未声明的构建环境行为。

### 4.3 手动切换

- 切换后立即更新 Context、`document.documentElement.lang` 与 Cookie。
- 不刷新页面，不重新挂载 3D Stage。
- Locale Provider 放在 3D Scene 生命周期之外；内容切换可以重渲染文案组件，但 `LivingRingStage` 的 Canvas、GLB 与 Journey ref 必须保持同一实例。
- Cookie 使用长期有效期和 `SameSite=Lax`。
- 切换控件可键盘操作，并有中英文可理解的 `aria-label`。

## 5. 移动端设计

### 5.1 断点与布局

主要断点：

- Desktop：`>= 1024px`
- Tablet：`768px–1023px`
- Mobile：`< 768px`

移动端内容采用单列：

- 首屏 Logo、标题、介绍依次排列；
- Flash/Vibe 对比由左右两栏改为上下两段；
- Flash/Vibe 场景、Logo Loop、说·触·感和系统链路均纵向展开；
- CTA 文案、戒指、二维码依次排列，二维码保持可扫描尺寸。

标题使用 `clamp()` 控制，避免中英文在 320–430px 宽度下溢出。正文行宽控制在适合手机阅读的范围，所有可操作区域至少 44px。

### 5.2 移动端戒指路径

- 为移动端定义独立 Journey 锚点，不复用桌面端左右穿梭坐标。
- 戒指主要沿中轴或内容空隙下行，只有在场景图和说·触·感节点处做轻微横移。
- 最大显示宽度受视口限制，避免遮挡标题和正文。
- Section 高度变化或语言切换后重新测量锚点，但不创建新的 Ring Scene。
- 在移动端降低 Canvas DPR 上限并关闭非必要后处理；保留材质、触控区和基本色彩变化。

### 5.3 动效降级

- `prefers-reduced-motion: reduce` 时禁用连续旋转、Shuffle、Decrypt 与滚动弹跳，只保留稳定最终状态。
- 低性能移动设备上以变换和透明度为主，不使用大面积实时模糊。
- Logo 与二维码不参与高频滚动动画。

## 6. 资源处理

新增资源建议：

```text
ring-demo/public/brand/eureka-logo.png
ring-demo/public/community/eureka-ring-wechat-group.png
```

- 保留原始图片，不覆盖用户源文件。
- Logo 在浅色首屏直接展示；深色 CTA 中放入克制的浅色品牌底板，避免白底突兀。
- 二维码不得经过有损压缩、模糊滤镜、旋转或透视变形。

## 7. 可访问性与 SEO

- 根据当前语言同步 `<html lang>`。
- 所有图片提供对应语言的 `alt`。
- 语言切换使用真实 `button`。
- 保持标题层级只有一个 `h1`，Section 标题继续使用有序层级。
- 页面标题和描述根据语言同步更新。
- QR 说明不能只依赖图片内文字。

## 8. 验收标准

### 语言

- 模拟 `CN` 请求首次进入中文；模拟其他国家进入英文。
- 手动切换后刷新仍保持选择。
- 本地 Vite 开发不依赖 Vercel 服务也能正常启动。
- 切换语言不会重载 GLB、重置滚动或出现双戒指。

### 品牌与二维码

- 首屏和 CTA 能看到 Eureka Logo，其他 Section 不重复堆叠。
- 最终 CTA 使用真实二维码，并可被常见手机扫码识别。
- 截图中的临时有效期文案不进入 Landing Page 的视觉内容。

### 响应式

- 重点检查 375×812、768×1024、1440×900。
- 页面无横向滚动条。
- 戒指不覆盖核心标题、正文、Logo、语言切换和二维码。
- 移动端滚动保持连续，Section 切换时不出现戒指重叠或跳变。

### 工程

- Landing 单元测试通过；
- TypeScript typecheck 通过；
- Vite production build 通过；
- 新增 Locale 解析与切换测试；
- 保留现有 Landing 动效与内容测试。

## 9. 非目标

本轮不包含：

- Flash/Vibe 真机 Demo 页面国际化；
- 多于中英文的第三种语言；
- 独立 `/zh`、`/en` SEO 路由；
- 用户账户语言同步；
- 二维码后台管理；
- 重新设计已有桌面端内容叙事。
