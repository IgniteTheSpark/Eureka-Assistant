# Theme V2 首页与主导航视觉一致性设计

> 日期：2026-08-03
> 状态：已确认设计，待实施
> 范围：Theme V2 今日首页、日历/资产库根页面标题、底部 Dock 与首页资产图标

## 目标

在不调整 Theme V2 整体架构、导航层级和数据契约的前提下，解决以下视觉与语义
不一致：

- 今日首页最外层面板与底部 Dock 过近，整页像一个贴住导航的封闭盒子。
- Next Moment、Reka 和今日生成没有形成三个清晰、独立的内容区域。
- 首页球池和 Agenda 使用临时 Material Icon 映射，与资产库、详情和资产类型不一致。
- 今日、日历、资产库三个根页面的标题存在尺寸和有无差异。
- Dock 的今日入口使用闪光图标，不能直接表达“主页”。

首页保留现有高辨识度的大数字水印、真实物理碰撞、设备重力、拖动和球体转动。

## 方案选择

底部区域考虑过三种表达：

1. **开口式重力舱（采用）**：顶部不画硬边界，球从页面上方落入；侧面和底部以
   淡边界、渐变和圆角形成容器，大数字水印位于球体后方。
2. **完整玻璃卡片（不采用）**：容易与前两个容器统一，但会把最具动感的区域也
   变成普通 Dashboard 卡片。
3. **仅保留底部托盘（不采用）**：视觉最戏剧化，但容器边界过弱，用户难以理解
   球体的反弹范围，也不符合三个独立 Container 的要求。

采用方案 1。重力舱是第三个独立容器，但有意使用不同于普通卡片的边界语言。

## 首页信息架构

移除当前包围整个 `HomeTodayPanel` 的外层白色面板、整页描边、整页圆角和整页阴影。
今日根页面改为背景上的四层纵向结构：

```text
今日                         统一页面标题

[ Next Moment ]             独立容器 1

[ Reka ]                    独立容器 2

      ○  ●  ○               从开放顶部落入
  │
  │                  29     独立容器 3：开口式重力舱
  │              今日生成
  ╰────────────────────╯

             Dock
```

- 页面左右统一留白 `18px`。
- 页面标题顶部间距 `14px`，标题与首个容器间距 `14px`。
- 三个容器之间保持 `12px` 垂直间距。
- 页面内容结束后保留至少 `24px` 视觉留白；Shell 继续负责 Dock 的安全区和触控
  Clearance，首页不再使用固定高度把内容推到 Dock 边缘。
- 411px 参考宽度保持现有 Next Moment 和 Reka 的信息密度；更窄设备允许纵向滚动，
  不通过压缩文字或球体来强行适配。
- Home Agenda 是今日页的次级状态，继续使用今日根标题与相同页面留白，不重新引入
  整页外框。

## 开口式重力舱

### 容器外观

- 使用 `surface` 到 `background` 的轻微纵向渐变区分物理区域。
- 左、右、底部保留低对比度边界；顶部不画实线，通过约 `40–56px` 的透明渐变形成
  开口。
- 底部使用与其他首页容器一致的圆角半径；顶部视觉上保持开放。
- Light/Dark 都使用 Theme V2 Token，不引入固定黑色 Dock 或容器颜色。
- 重力舱在 411px 参考宽度下保持足够物理高度；小屏可随页面滚动，大屏可增加舱体
  高度，但不拉伸球体。

### 水印

保留现有大数字水印，并把它作为重力舱的主要视觉识别：

- 数字使用 `poolTrueCount`，显示当天真实生成总数，而不是最多 50 个物理球的数量。
- 大数字位于右下视觉区但不紧贴底边，字号保持约 `96–112px` 的比例感。
- 数字颜色使用 Accent 的约 `6–8%` 透明度；小字“今日生成”使用约 `24–30%`。
- 渲染层级为：容器背景 → 水印 → 球体 → 交互反馈。球体可以自然经过并遮挡
  水印，形成空间层次。
- 不再额外增加一条普通卡片式 Header，避免“今日生成”重复出现。

### 物理与交互

- 新增球体从重力舱顶部开口附近生成，随后受设备重力影响落下。
- 物理碰撞边界仍覆盖完整舱体；顶部边界只在视觉上开放，避免球体离开可交互区域。
- 保留球体之间的碰撞、拖动、点击打开资产以及随滚动/页面生命周期暂停物理计算。
- 保留当前球体图标随球体姿态转动的实现，不把图标强制保持垂直。
- 开启 Reduce Motion 时使用稳定静态布局，仍保留水印和可点击的最小 44px 目标。

## 资产图标统一

首页不再维护 `_assetIcon` 和 `_agendaAssetIcon` 两套临时 Material Icon 映射。
`TodayData` 已包含来自技能注册表的 `skills` 元数据，球池与 Agenda 都通过现有
Canonical Skill Resolver 获取图标：

| 类型 | Canonical 图标 |
| --- | --- |
| todo | 📋 |
| event / calendar | 📅 |
| contact | 👤 |
| notes / note / legacy idea / misc | ✍️ |
| expense | 💳 |
| custom skill | 服务端技能配置中的图标 |
| unknown | • |

具体规则：

- 球体由 Material `IconData` 改为渲染 Canonical Glyph，从而支持自定义技能图标。
- 自定义技能优先使用注册表元数据；缺失时才使用内置别名和 fallback。
- expense 的客户端 fallback 收敛为 `💳`，与当前资产详情和 Render Spec 对齐。
- 删除首页中 `expense → restaurant`、未知类型 → sparkle 等发散映射。
- Resolver 只保留一个事实来源，首页、Agenda、时间流和 Core Detail 不再各自定义
  不同 fallback。

本项不增加 API 请求，也不修改后端数据模型。

## 主页面标题统一

新增一个仅用于三个根 Tab 的共享页面标题样式：

- 文案分别为“今日”“日历”“资产库”。
- 使用 `22px`、Semibold/Bold、Theme V2 Foreground，保持紧凑但具有清晰页面层级。
- 左侧 `18px`、顶部 `14px`，标题后的内容间距统一。
- 今日标题从原整页面板内移到页面层。
- 资产库从当前 `headlineMedium` 收敛到共享标题。
- 日历的 Flow/Month/Year 根视图上方新增“日历”；日期、月份、年份仍是内容标题，
  不替代页面标题。
- 日历 Day Detail/Schedule、资产库容器详情等次级页面继续显示其上下文标题，不强行
  叠加根页面标题。

## Dock

- 今日入口由闪光图标改为明确的主页语义：未选中 `home_outlined`，选中
  `home_rounded`。
- 日历和资产入口暂不改变图标或导航顺序。
- Dock 继续使用已有的 Light/Dark Surface Token、Safe Area 和 `contentClearance`。
- 首页通过流式布局和内容底部留白与 Dock 分离，不扩大 Dock 阴影或增加黑色底板。

## 状态、错误与可访问性

- 首页 Loading、Empty、Refresh Error 仍占据相同页面布局，不重新套整页 Surface。
- 重力舱在没有资产时仍显示水印 `0` 和空态说明，容器不会坍缩消失。
- 三个根页面标题提供 Header Semantics；Dock 保持可选择语义和 44px 最小触控区域。
- 球体继续暴露资产名称、类型和按钮语义；Canonical Emoji 不作为唯一的类型说明。
- 字体放大和 360px 宽度下允许滚动，不遮挡 Dock、不产生 RenderFlex Overflow。

## 测试与验收

采用 TDD，先更新/增加失败测试，再实现：

1. 今日页不再存在整页外框，Next Moment、Reka、重力舱具有三个独立 Key 和边界。
2. 411px、360px 下页面留白、滚动和 Dock Clearance 不重叠。
3. 球体从舱体上边缘生成，仍具有碰撞、重力、拖动、点击和转动。
4. Reduce Motion、页面非活动状态和前后台切换不会持续运行物理 Ticker。
5. 内置、别名、自定义和未知资产类型均解析到唯一 Canonical Glyph；expense 为
   `💳`，不再出现餐饮图标。
6. 今日、日历、资产库根页面都使用相同的标题样式和水平位置。
7. Dock 今日入口在选中/未选中状态使用 Home 图标并保留 Semantics。
8. 更新 Home、Calendar、Library 的 411 Light/Dark Golden，并覆盖 360px 首页。
9. Flutter Analyze 和相关 Widget/Golden 测试通过。
10. 在连接的 Android 真机上验收三 Tab 标题、Dock 间距、球体下落/碰撞/转动以及
    资产打开流程。

## 非目标

- 不调整 Theme V2 Shell 导航架构或三个 Tab 的顺序。
- 不重新设计 Next Moment、Reka 内部的信息内容和业务逻辑。
- 不修改资产、技能、日历或 Report 的后端 API。
- 不改变球池最多 50 个物理 Body 的性能上限。
- 不把日历的日期/月份/年份内容标题强行统一为页面标题样式。

## 完成标准

- 首页视觉上是三个独立区域，没有包围整页的大面板。
- 今日生成以开口式重力舱呈现，并保留大数字水印和完整物理体验。
- 首页内容与 Dock 之间有明确留白，在 360px 和 411px 设备上均不贴边或遮挡。
- 首页球池、Agenda、资产库/详情对同一资产类型使用相同图标。
- 今日、日历、资产库根页面标题的文案层级、字号和对齐一致。
- 真机可以点击球体打开对应资产，现有业务流程不回退。
